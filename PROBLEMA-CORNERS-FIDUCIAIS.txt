O QUE DEVERIA FAZER (CORRETO):
───────────────────────────────

Usar o CANTO EXTERNO (bounding box corner) em vez do interno:

  Para TL marker:    corner = (bbox_x, bbox_y)
  Para TR marker:    corner = (bbox_x + bbox_w, bbox_y)
  Para BR marker:    corner = (bbox_x + bbox_w, bbox_y + bbox_h)
  Para BL marker:    corner = (bbox_x, bbox_y + bbox_h)

SOLUÇÃO:
────────

Adicionar nova função em omr-service/omr/fiducial.py:

  def _extract_external_corners(markers, img_width, img_height):
      """
      Extract external corners (page corners) instead of internal corners.
      """
      external_corners = []
      
      for m in markers:
          cx, cy = m["cx"], m["cy"]
          x, y, w, h = m["x"], m["y"], m["w"], m["h"]
          
          is_left = cx < img_width / 2
          is_top = cy < img_height / 2
          
          if is_left and is_top:      # TL
              corner = (x, y)
          elif not is_left and is_top: # TR
              corner = (x + w, y)
          elif not is_left and not is_top: # BR
              corner = (x + w, y + h)
          else:                         # BL
              corner = (x, y + h)
          
          external_corners.append(corner)
      
      return external_corners
