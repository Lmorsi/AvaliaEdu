VERSÃO 1.0 - Repositionamento de L-Markers
────────────────────────────────────────────
Problema:   L-markers muito perto do QR code
Solução:    top: 8mm → 55mm, left/right: 1mm → 12mm
Resultado:  L-markers separados e bem posicionados
Status:     ✅ COMPLETO


VERSÃO 2.0 - Contenção de Bolhas
─────────────────────────────────
Problema:   Bolhas ultrapassavam os L-markers
Solução:    padding: 8mm → 24mm (horizontal), +16mm (vertical)
Resultado:  Todas as bolhas contidas dentro da zona
Status:     ✅ COMPLETO


VERSÃO 3.0 - Aproveitamento de Espaço
──────────────────────────────────────
Problema:   Q1 começava na mesma linha dos L-markers
Solução:    margin-top: 0mm → 3mm
Resultado:  Q1 bem afastada, espaço aproveitado
Status:     ✅ COMPLETO


VERSÃO 4.0 - Otimização de Layout
──────────────────────────────────
Problema:   4 colunas muito estreitas, D caía para baixo
Solução:    4 colunas (15 Q) → 3 colunas (20 Q), flex-wrap: wrap → nowrap
Resultado:  3 colunas largas, sem quebra de linha
Status:     ✅ COMPLETO


VERSÃO 5.0 - Melhorias de Detecção OMR
───────────────────────────────────────
Problema:   Bolhas com pouca espessura, Q1 ainda perto dos L-markers
Solução:    border: 2px, margin-top: 6mm
Resultado:  Bolhas mais robustas, melhor detecção
Status:     ✅ COMPLETO


VERSÃO 6.0 - Calibração de Marcadores L
────────────────────────────────────────
Problema:   L-markers não calibravam (TL/TR/BL/BR não alinhados)
Solução:    L-markers: 12px → 16px, bolhas: 18px → 16px, border: 2px → 3px
Resultado:  Marcadores robustos, bolhas otimizadas
Status:     ✅ COMPLETO

TAREFA 4: Validação Visual - test_bubbles.html
─────────────────────────────────────────────────

O que é:    Teste visual para garantir que imagem CORRIGIDA não fica DISTORCIDA
Por quê:    Validar qualidade da correção de perspectiva antes de testes OMR reais
Como:       1. Gerar PDF
            2. Imprimir documento (300 DPI)
            3. Fotografar com ângulo (15-30°)
            4. Upload em test_bubbles.html
            5. Validar 4 imagens de resultado

Esperado:   Corrected Image frontal, sem distorção, nítida
Status:     ⏳ PRONTO PARA EXECUTAR
