        ┃                           ┃                            ┃
    ┌───▼──────┐             ┌────▼─────────┐         ┌─────▼─────────┐
    │  TL      │             │  TR          │         │  BR    BL     │
    │(1/8 ROI) │             │ (1/8 ROI)    │         │(1/8 ROI)      │
    └───┬──────┘             └────┬─────────┘         └─────┬─────────┘
        │                        │                         │
        │ PARA CADA CANTO:       │                         │
        │ ═════════════════════════════════════════════════════════════════════
        │
        ├─► [1] Extrair ROI de 1/8 × 1/8 da imagem em cada canto
        │       └─► Ignora teclado, mesa, fundos (fora da ROI)
        │
        ├─► [2] BINARIZAÇÃO ADAPTATIVA
        │       └─► cv2.adaptiveThreshold(blockSize=11)
        │           ├─ Calcula threshold local para cada vizinhança
        │           └─ Lida com iluminação não uniforme (sombras)
        │
        ├─► [3] BINARIZAÇÃO OTSU
        │       └─► cv2.threshold(..., OTSU)
        │           ├─ Threshold global automático
        │           └─ Separação foreground/background sem ajuste
        │
        ├─► [4] COMBINAÇÃO DUPLA (AND)
        │       └─► binary = AND(adaptativa, otsu)
        │           ├─ Requer passar em AMBOS os critérios
        │           ├─ Reduz ruído em ~80%
        │           └─ Pixels mais confiáveis
        │
        ├─► [5] DESFOQUE GAUSSIANO
        │       └─► cv2.GaussianBlur(kernel=5×5, sigma=1.0)
        │           ├─ Suaviza artefatos isolados
        │           ├─ Mantém estrutura principal
        │           └─ Prepara para Harris
        │
        ├─► [6] HARRIS CORNER DETECTION
        │       └─► cv2.cornerHarris(blockSize=2, ksize=3, k=0.04)
        │           ├─ Detecta mudanças em 2 direções (cantos)
        │           ├─ Mais robusto que detecção de linhas
        │           └─ Retorna "força" de canto para cada pixel
        │
        ├─► [7] NORMALIZAR E THRESHOLDAR
        │       └─► harris_norm = normalize(0, 255)
        │           └─► strength > 10% * max ─► cantos fortes
        │
        ├─► [8] FILTRAGEM POR FORÇA
        │       └─► Pega TOP 10% dos cantos mais fortes
        │           ├─ Ordena por "força Harris"
        │           ├─ Mantém apenas top 10%
        │           └─ Remove cantos fracos (ruído)
        │
        ├─► [9] ANÁLISE DE CENTROIDE
        │       └─► Calcula centro dos 10% top
        │           ├─ centroid_x = mean(x dos 10%)
        │           ├─ centroid_y = mean(y dos 10%)
        │           └─ Define "zona de confiança"
        │
        ├─► [10] FILTRAGEM POR DESVIO PADRÃO (2-SIGMA)
        │        └─► Calcula distância de cada canto ao centroide
        │            ├─ distance = √[(x-cx)² + (y-cy)²]
        │            ├─ mean_dist = mean(todas as distâncias)
        │            ├─ std_dist = std(todas as distâncias)
        │            ├─ Threshold = mean_dist + 2 * std_dist
        │            ├─ Mantém apenas: distance ≤ threshold
        │            └─ Remove outliers isolados (ruído)
        │
        ├─► [11] SELEÇÃO DO CANTO EXTREMO
        │        └─► Baseado no target_corner:
        │            ├─ TL: min(x + y)         ─► Superior-esquerdo
        │            ├─ TR: max(x), min(y)     ─► Superior-direito
        │            ├─ BR: max(x + y)         ─► Inferior-direito
        │            └─ BL: min(x), max(y)     ─► Inferior-esquerdo
        │
        └─► RESULTADO: (x, y) do canto detectado

╔════════════════════════════════════════════════════════════════════════════╗
║                       COMPARAÇÃO: ANTES vs DEPOIS                          ║
╚════════════════════════════════════════════════════════════════════════════╝

ANTES (HoughLinesP):
───────────────────────────────────────────────────────────────────────────
    Imagem Raw
        ↓
    Canny Edges
        ↓
    HoughLinesP (detecção de linhas)
        ↓
    ❌ Linhas finas não detectadas
    ❌ Ruído (mesa) interfere
    ❌ Resultado: Bordas da imagem
        ↓
    ❌ Perspectiva INCORRETA
        ↓
    ❌ Bolhas fora de posição
        ↓
    ❌ RESPOSTA ERRADA


DEPOIS (Harris Corner Detection):
───────────────────────────────────────────────────────────────────────────
    Imagem Raw
        ↓
    Binarização Adaptativa → Otsu
        ↓
    Combinação AND (reduz ruído 80%)
        ↓
    Desfoque Gaussiano
        ↓
    Harris Corner Detection
        ↓
    Filtragem por Força (top 10%)
        ↓
    Análise de Centroide
        ↓
    Filtragem por Desvio Padrão (2-sigma)
        ↓
    Seleção de Canto Extremo
        ↓
    ✓ Cantos reais detectados
    ✓ Ruído filtrado efetivamente
    ✓ Resultado: Marcadores L nos cantos
        ↓
    ✓ Perspectiva CORRETA
        ↓
    ✓ Bolhas na posição certa
        ↓
    ✓ RESPOSTA CORRETA
